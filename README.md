# Kursor Plik (mod Fabric)

1. Wpisz wersje yarn i fabric-api w gradle.properties (https://fabricmc.net/develop/, Minecraft 1.21.11).
2. Uruchom: ./gradlew build  (potrzebny Gradle 9.x lub wrapper z fabric template)
3. Jar bedzie w build/libs/kursorplik-1.0.0.jar - wrzuc do mods/ razem z Fabric API.

Komenda: /kursorplik -> przycisk WLACZ/WYLACZ. Gdy wlaczony, PPM na blok lub klik na hologram/item pokazuje id i klucz tlumaczenia na czacie.
